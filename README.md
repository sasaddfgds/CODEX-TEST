# ImGui "привет" example

Небольшая программа на C++ с Dear ImGui, которая выводит слово `привет`:
- в консоль (`std::cout`),
- в стилизованном интерфейсе ImGui.

Что добавлено по визуалу:
- современная тема со скруглениями и акцентными цветами,
- аккуратные вкладки (`TabBar`) вместо дефолтного «старого» вида,
- верхнее меню и вкладка параметров для настройки стиля в реальном времени.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/imgui_privet
```
